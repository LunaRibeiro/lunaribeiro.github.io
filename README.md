# Luna Ribeiro — Desenvolvedora Web

Meu portfólio pessoal: quem eu sou, os serviços que ofereço, projetos que já desenvolvi e um formulário de orçamento que abre direto no WhatsApp.

**Acesse:** [lunaribeiro.github.io](https://lunaribeiro.github.io)

## Tecnologias

- HTML5 semântico
- CSS3 (Grid, Flexbox, custom properties, animações)
- JavaScript puro (sem frameworks)

## Destaques

- Layout responsivo, do celular ao desktop
- Projetos renderizados a partir de uma lista em JavaScript
- Formulário com validação que monta a mensagem de orçamento para o WhatsApp
- Acessibilidade: navegação por teclado, textos alternativos e respeito ao `prefers-reduced-motion`
